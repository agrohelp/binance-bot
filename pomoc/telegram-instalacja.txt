#   (telefon + komputer)

# ------------------------------------------------------------
# 1. INSTALACJA NA TELEFONIE (Android / iPhone)
# ------------------------------------------------------------

# Android:
#   Otwórz Google Play → wpisz "Telegram" → zainstaluj.

# iPhone:
#   App Store → wpisz "Telegram" → zainstaluj.

# Po instalacji:
#   • uruchom aplikację
#   • podaj numer telefonu
#   • wpisz kod SMS
#   • ustaw nazwę (może być "Karol")


# ------------------------------------------------------------
# 2. INSTALACJA NA KOMPUTERZE (opcjonalnie)
# ------------------------------------------------------------

# Wejdź na:
#   https://desktop.telegram.org/

# Pobierz wersję:
#   • Windows
#   • Linux
#   • Mac

# Po uruchomieniu:
#   • kliknij "Start Messaging"
#   • zeskanuj kod QR telefonem (Telegram → Ustawienia → Urządzenia → Połącz urządzenie)


# ------------------------------------------------------------
# 3. SPRAWDZENIE, CZY TELEGRAM DZIAŁA
# ------------------------------------------------------------

#   "Telegram" (oficjalny kanał)
#   "Telegram Tips"

# Jeśli możesz otworzyć — działa poprawnie.
